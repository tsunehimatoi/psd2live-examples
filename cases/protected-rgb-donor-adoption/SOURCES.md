# Sources and boundaries

This is a new standalone implementation of a constrained pixel-adoption
contract. No function was copied from the earlier character-specific scripts,
their adapters, sprite-gen or mesh-avatar-studio. It uses only Python standard
library functions and an installed Pillow dependency. The original geometric
fixture, its exact target formula and the whole-crop control were created for
this executable demonstration.

The earlier local workflow records were consulted for the distinction between
pre-inference reference I/O failure, rejected completed candidates, and bounded
RGB adoption. The stored historical report records 140,628 adopted pixels and
961,067 outside-edit differences rejected. These are historical report values,
not measurements from this package. No associated private image or source file
is distributed and no original historical prompt is reconstructed.

and [Kirishima Mio example](https://github.com/tsunehimatoi/psd2live-examples/blob/32bc3487d6fbc29f1680d4c70b94e526f6b944a8/cases/kirishima-mio/README.md)
already describe generated layer separation, registration and occlusion
completion. This contribution demonstrates safe adoption at already-known
coordinates; it does not claim those workflows lack completion, or that this
tool replaces their image generation or registration.

No full character, PSD2Live editor, live renderer, motion or GPU acceptance was
repeated in this demonstration. Completing this tool package does not change
the unresolved playback acceptance status of the separate character project.
