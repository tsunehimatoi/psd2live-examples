# Live2D 高精度直播模型:建模工作流与「插画拆层」调研

> 面向:已有 Live2D 建模基础、想做"高精度直播模型"的建模师。
> 调研日期:2026-10-12(Asia/Shanghai)。
> 标注说明:
> - 【官方】= Live2D 官方手册/教程原文可查;
> - 【多源】= 两个以上模型师/教程一致;
> - 【单源】= 仅一位作者的经验;

## 0. 一页结论(TL;DR)

1. 拆层的本质是「先拆后补」:按运动需求切开 → 把所有"动起来会露出来"的区域**补画出来** → 叠回原图逐像素核对 → 每个部件合并成一层 PSD 导入。【官方+多源】
2. 补全量没有标准数字,官方只给原则:大动作部件、会被别的部件遮挡的部件,"事先多画";嘴内"比原图大一圈";脖子"画到嘴/鼻尖高度";头发"别忘了被遮住的部分,否则会断开"。【官方/多源】
3. 直播模型的核心是**头部**:眼、嘴、前发、发落影拆得越细越好;身体按"上半身出镜"拆到够用即可。【多源】
4. 分辨率:PSD 画布宽 4000–6000 px、高 6000–8000 px(350 dpi 下 3000×6000 是下限推荐);四周留 ≈500 px 空白;图集用 4096×4096,尽量别上 8192。【多源】
5. 兼容性红线:PSD 必须 RGB / 8bit / sRGB;图层混合只用 正常/正片叠底/线性减淡(添加)——VTube Studio 等追踪软件不支持更多混合模式(即使 Cubism 5.3 支持);同名图层要避免;导入 PSD 每部件一层(线稿+填色合并)。【官方+多源】
6. AI 的正确用法:**只用 AI 生成"被遮挡区域"的补全层(新建图层、放在原部件之下),可见像素保持原图**;AI 一次性"自动拆层"(See-through、Qwen-Image-Layered)只能产出草稿,头发束、围巾、系带等仍需人工。线稿线宽、颜色、阴影一致性必须靠人工收尾和"叠回原图差值检查"。
7. 附 §6:半身正面少女 约 71 层的双语图层清单(+扩展清单),可直接作为交付 PSD 的模板。

## 1. 完整流程概述(立绘 → 拆层 → 网格 → 变形器 → 参数 → 物理 → 动作 → 导出)

官方生产流程把 Cubism 制作分成四步:①素材处理 ②建模 ③动画 ④导出/嵌入。【官方 Production Flow】下面按直播模型细化:

| # | 阶段 | 要做什么 | 产出 / 注意点 |
|---|------|----------|----------------|
| 0 | 立绘设计/定稿 | 纯正面、左右对称(脸部尤其)、人物尽量充满画布;发型/服装设计时就考虑可动性(关节处无复杂花纹、飘带画成"直"状态再拆)。 | 完成图 + 表情/嘴型/闭眼指引草图。【多源:Moonku、ささめた、CLIP STUDIO TIPS】 |
| 1 | **拆层(素材分割)** | 复制原画 → 每个部件放进以部件命名的组 → 用图层蒙版切出该部件 → **新建图层补画**被遮挡部分(不要直接涂在原图层上) → 叠回原图检查缺口。保留两份 PSD:`xxx_素材分割.psd`(可编辑,含蒙版/文件夹)与 `xxx_import.psd`(每部件合并为一层)。 | 官方还提供 Photoshop「素材分割」插件(裁剪 Crop / 扩展 Expand),可对线稿、填色、阴影多图层同时操作。【官方】 |
| 2 | 导入 PSD → ArtMesh | Cubism Editor 将每个图层自动生成最少顶点的 ArtMesh,默认相对图层大小留 1 px 边距(可在 环境设置→建模 中改)。PSD 过大时会提示建议以一半尺寸预览。 | 导入前清除杂点、同名图层、隐藏层、路径信息(PS CC2019+ 的路径可能导致导入失败)。【官方】 |
| 3 | 网格编辑 | 在轮廓、会形变的位置(眼睑、嘴角、关节、发束弯曲点)加顶点;大面积平面少加。高精度模型要在"形变热点"补顶点,否则插值时出现收缩/锯齿。 | 通行做法(无单一来源);注意线性插值会让大角度旋转的 ArtMesh 收缩——需要保形旋转时用旋转变形器。【官方 Deformer 页】 |
| 4 | 变形器(Deformer) | 旋转变形器:脖子、手臂、关节、摆动物件;弯曲(Warp)变形器:头发、面部立体、呼吸、身体倾斜等。建立"部位→变形器层级",必要时用胶水(Glue)连接部件。 | 官方:旋转变形器可无收缩地转动;Warp 变形器可对内部网格整体变形并可调尺寸/透明度。【官方】 |
| 5 | 参数与关键形(Keyform) | 按标准参数 ID 建立:角度 XYZ、眼开合/微笑、眼球 XY、眉毛、嘴开合/嘴形、脸颊、身体 XYZ、呼吸、手臂/手、头发摆动、肩/胸等。眼睛嘴巴:"闭=0,开=1"。 | 官方建议未特别规定时用标准参数表的 ID 和范围,以便共享动作、被 VTube Studio 等自动识别。【官方】 |
| 6 | 物理运算 | 以角度/身体角度为输入,头发、饰品、围巾、胸部等为输出,设置单级/多级摆锤(pendulum)。输出参数常用 ParamHairFront/Side/Back、ParamBustX/Y 等("通常由物理设置")。 | 【官方 Physics 教程 + 标准参数表】 |
| 7 | 表情与动作 | 表情文件(.exp3.json)用于直播切换(脸红、星星眼、舌出等差分);动作在 Animation 工作区用 Dope Sheet/Graph Editor 制作(.motion3.json)。直播以追踪软件驱动为主,动作用于热键/待机。 | 【官方 Production Flow】 |
| 8 | 导出 | `File → Export For Runtime → Export as .moc3`;Export Version 选 SDK 3.0/3.3/4.0/5.0 或更新;务必勾选导出 physics3.json(与模型一起导出,才会写入 model3.json);Export Types: SDK;模型文件夹含 .model3.json/.moc3/.cdi3.json/.physics3.json/纹理(如 xxx.4096/);另放 512×512 图标。VTube Studio 只读参数 **ID**,不读参数名。 | 大纹理在手机上可能卡顿甚至崩溃。【VTube Studio Wiki】 |

> 关键提醒:动画/追踪的"高精度"取决于第 1 步。官方原话:素材分割的工作量与程度会决定模型质量;如果补画不足,部件移动时会"看起来断开"。【官方 §1 插图加工】

## 2. 拆层规范重点

### 2.0 总原则(多源一致)

- **从大到小、从前到后**:先拆最上层(前发、呆毛),再拆其下的脸部器官,最后拆被遮挡的底层(后发、脖子、身体)。理由:头发在脸部件最前面,轮廓常被头发遮住,先切头发后续效率最高。【CLIP STUDIO TIPS(MUGENUP)、B站官方指南大纲"从大到小/先拆后补"】
- **动的东西不同就分开,层次不同就分开,左右不同就分开**(物体、层次、功能三维度分离)。【ささめた/Zola 与 Moonku 文章一致】
- **补画用新图层,不要改原图层**;补画时分层保存,便于后期再改。【官方 + k-illust】
- **分割阶段阴影用"正常"混合**而不是正片叠底:多个乘算阴影重叠会越叠越深,拆开后难以匹配。【CLIP STUDIO TIPS】
- **落影要跟着部件拆**:前发落在脸上的影、侧发落影、头落在脖子上的影等,"部件拆多细,落影就拆多细"。影的范围比轮廓画大一圈,因为 Live2D 里可用剪贴蒙版(Clipping ID)裁剪。【ささめた、夏水かなた、双葉うず、CLIP STUDIO TIPS】
- **对称**:脸(痣、前发、鼻除外)必须以画布中线严格左右对称;脸中心对齐画布水平中心;宽度用偶数。【双葉うず、ささめた】
- **衣服/动作设计**:关节处避免网袜/格纹/透明叠层;飘带、链条先画成"直"的状态再动;手臂上下臂关节处画成圆形,作肘使用。【CLIP STUDIO TIPS、ささめた】
- **不要过度拆分**:先定好"质量线"(用途:只聊天?上半身?全身?),不必要的部件不拆,避免工作量爆炸与管理复杂。【CLIP STUDIO TIPS、なりゅう】

### 2.1 各部件拆分与补全要点

> 表中【经验值】的像素数默认基于"画布约 4500×6500 px、头宽约 1400–1700 px、单眼宽约 220–300 px"的半身立绘,请按你的实际头宽成比例缩放(比例已在括号内给出)。

| 部件 | 怎么拆 | 被遮挡部分必须补全的范围 | 重叠量/安全边【经验值,除非标注来源】 |
|------|--------|--------------------------|----------------------------------------|
| **前发** | 官方:前发/侧发/后发三分;左右分开的鬓发、双马尾分左右;要动的呆毛单独成层。进阶:按"发束/发片"拆;前发 3–5 束(中/左/右/碎发)。 | 被前面发束压住的那段发根、发束之间被遮住的线条与阴影("线稿也要补"),发梢被遮的部分。 | 发束根部向发际内延伸 ≥ 发束宽度的 1–2 倍(≈ 60–150 px);相邻发束互相搭接 ≥ 20–40 px。CLIP STUDIO TIPS 的警示:补得太短会在动画时出现"头发从脸颊长出来"的效果,应补到 **耳上方的"发生点"**;发结类与头部贴合的部件可只补一半。 |
| **前发落影** | 与前发同数量拆分(前发拆几束,落影拆几份)。 | 影的范围比实际轮廓画大一圈,头发被拨开时脸上仍有合理的影。 | 向发际线外/脸内各多画 30–60 px(≈ 0.03 头宽);用阴影色,**混合模式用正常**。 |
| **侧发/鬓角** | 官方:左右各一层;ささめた:与后发之间需要"中间束"(侧发与后发间有空隙时),侧面角度才好看。 | 侧发被前发压住的上部、被脸遮住的内侧;耳朵上方一直补到头皮。 | 向上补到耳上方/鬓角发际,≥ 80–150 px;侧发内层(里侧)整体补完整。 |
| **后发** | 后脑(底色/发旋/发结/线稿分层)+ 发束分片(左/中/右/内外层/表里)。长发可前中后、里外分层;马尾/双马尾单独拆,翻转的发束表/里分开。 | 被脸、身体、前发遮住的**整个后脑与发束根部**,被肩/手臂遮住的下半段。 | 后脑画成完整球形,超出轮廓外 ≥ 100 px;发束根部深入后脑 ≥ 150 px;发束被遮部分补到可见部分之后至少 1/3 长度。ささめた:只要可见范围画不够就"差し戻し"。 |
| **呆毛/碎发** | 单独分层,最靠前的毛束不需要补画;靠后的毛束补根部(用阴影色吸色补)。 | 呆毛根部(与头发重叠处)。 | 根部向头发内部延伸 ≥ 毛束宽度 × 2(≈ 40–80 px)。 |
| **脸(轮廓)** | 脸底色(只含肤色)与脸线稿分层(Moonku/夏水:线与填色分开;官方:导入前需合并为一部件一层——可保留线稿与影为独立部件)。 | **画出被头发盖住的整个头型**(含头顶、颞部、被鬓发遮的脸颊),填成纯肤色,画成**圆头**更易出立体感。 | 头型向头发内部延伸到 ≥ 头顶/后脑轮廓,即整颗头完整可见;脸颊与鬓角交界留 30–60 px 重叠。 |
| **发际(生え際)** | 单独的"发际肤色/发际阴影"小层,放在前发之下。(ささめた) | 刘海被拨开/摆动时露出的皮肤、发际线。 | 沿发际线向额头内外各 20–50 px。 |
| **耳朵** | 官方:可并入轮廓,但单独分左右更好控制;ささめた:基本一层,要精的话外轮廓与耳内分开;耳饰/耳环必须单独。 | 被鬓发遮住的耳廓上部与内侧。 | 补到完整耳形 + 向头部内侧再延伸 30–50 px。 |
| **眉** | 左右眉各一层;眉有阴影/深眼窝时再拆影。(Moonku、官方) | 一般无需补;被刘海遮住的眉段要补完整(刘海摆动时露眉)。 | 被遮眉段补到完整眉形。 |
| **鼻** | 一层即可;有高光/影时分开。 | 无。 | — |
| **眼(见 2.2)** | 白眼/虹膜/瞳孔/高光/上睫毛/外眼角翘起/眼皮(眼褶)/下睫毛,左右各一套。 | 白眼:完整杏仁形且超出睫毛线;虹膜:**完整圆**(含被上眼皮遮住的上缘);下眼睑等。 | 见 2.2。 |
| **嘴(见 2.3)** | 上唇、下唇、口内(口腔)、上齿、下齿、舌、嘴角/唇周肤色遮片,另有"吐舌"差分舌。 | 口内:按"最大张口"绘制,比原图大一圈;唇需补肤色部分遮住溢出的口内。 | 见 2.3。 |
| **脖子** | 脖子+头部落影(影剪贴到脖子上);胸锁乳突肌/喉结有则分开;颈线稿要和填色一起延长。 | **向上延长**:上抬头时脖子会露出来。官方:"画到嘴边";夏水:"画到眼下附近";ささめた:"比想象的长得多,到鼻尖附近",且**线稿与填色都要延伸**。 | 向上延伸到鼻尖/嘴高度;向下深入躯干 ≥ 100–200 px。 |
| **躯干/肩** | 官方:脖子/躯干/手臂/腿;ささめた:胸、胴体、腋(脇)分开,侧身时腋与躯干夹住手臂有立体感;锁骨独立;胸:左右分开才能"乳摇",躯干按腰线分上下才能扭腰;带丝带的拆开。 | 躯干上缘向上补到与肩重叠("胴体画太窄,侧身时会穿帮"),被手臂遮住的腋下躯干。 | 躯干上缘盖过肩 ≥ 100–200 px;与腰/裙交界重叠 ≥ 80–150 px。 |

| **衣服/领/襟** | 领(前/后/内侧)、开襟左右、袖上下段、下摆;外套内侧(裏面)需单独;ささめた:领子与开衫分开更易加动作。 | 外套/领的**内侧(里面)与线稿**要补;被领、领结、围巾遮住的部位。 | 里面补到外层被遮住的全部范围,线稿一并补;其余同"躯干"。 |
| **围巾/飘带/领结/挂饰** | 官方:躯干上摇动的东西要分开;CLIP STUDIO TIPS:先把弯曲的飘带/链条整理成**直的**再动;拆成多节(可做多关节物理)。 | 被身体/手遮住的飘带根部、围巾被盖住的内层与里面。 | 飘带每节向下一节内延伸 ≥ 带宽 × 0.5–1;根部深入躯干 ≥ 100 px。 |

### 2.2 眼睛(最关键)

- 官方最小拆法:睫毛 / 眼球 / 眼白 三件;外眼角翘起部分单独分更易变形;**眼白一定要补画**,因为眼球移动时会露出原来被眼球遮住的白色,且眼白可作为眼球的剪贴蒙版(Clipping ID)。【官方】
- 高精度拆法(Moonku 单眼):高光、眼褶+阴影、上睫毛、上眼皮、上眼线、眼球、眼白、下睫毛、下眼线、下眼皮。【单源】
- Palmie / なりゅう / ささめた:白眼、虹膜、**瞳孔**、大高光、小高光、反射光、上睫毛(主睫毛+细睫毛)、外眼角睫毛(**必须分**,否则做不出眨眼)、双眼皮线、上眼皮/下眼皮、下睫毛(显眼才分)。**"瞳孔相关能分都分,不需要的由建模师合并"**。【多源】
- 高光、闪光层的混合模式用"正常"(Palmie 推荐;发光/覆盖等在 Live2D 中不能完全还原)。【Palmie】
- **补全要点**
  1. 虹膜画成完整的圆(含被上眼皮、上睫毛遮住的上部);眼球上下移动、眨眼、眯眼时才不会缺块。
  2. 眼白画成完整的眼窝形状,边缘延伸进睫毛线之下、眼皮之下(【经验值】向外多 10–25 px ≈ 0.05–0.1 眼宽),因为眼白做"虹膜/高光/眼皮影的剪贴蒙版"。
  3. 眼皮(皮肤色)补画:闭眼时眼睛位置不能是"窟窿",需有肤色眼皮或上眼睑层覆盖(Zola:"闭眼后脸不能是个窟窿")。
  4. 影的拆分:前发的落影、眼周的影要单独拆,并重新叠放检查是否与前发落影色不一致。【CLIP STUDIO TIPS】
  5. 眼睛区域的发丝遮挡:CLIP STUDIO TIPS 强调直播模型不要让头发遮到眼睛——头发实时晃动会遮挡眼,设计时要避开。
  6. 剪贴蒙版数量有限:Cubism SDK for Native/Web 单模型最多 36 种 Clipping 排列、Unity 64/场景;眼睛左右各用白眼做蒙版就占掉一批,"高光/虹膜/睫毛"全用剪贴时容易超限,需在 File→Model Statistics 检查。【官方 Clipping Mask 页】
  7. 蒙版边缘白边:半透明边缘会透出底下 ArtMesh 的颜色,有官方绕过流程(复制蒙版 ArtMesh、放大、透明度 0%)。【官方】

### 2.3 嘴(口腔、牙、舌、唇)

- 官方:上下唇分开;口内单独拆,闭口时应看不到口内;**口内要画得比原图大一圈**;因此要在唇上加画一块**肤色遮片**盖住溢出的口内。官方说明"口内使用剪贴蒙版"的缺点:嵌入负载、口内可能从线稿外露出、变形越多工时越大;**推荐不用剪贴,而用肤色遮片**。适用剪贴的情形:视频用途、厚涂画风(唇周涂层不均)、嘴部变化少。【官方 §插图加工】
- 精细拆法(ささめた/夏水/Moonku/双葉うず):上唇、下唇、口内(底色)、奥齿、上齿、下齿、舌、吐舌差分舌(根部需与原舌重叠)、嘴角肤色遮片(口角两侧也需要)、下唇影。八重歯在唇上时线稿与填色分开。【多源】
- 口内部件按"**あ**(最大张口)"状态绘制(双葉うず)——"一番大きく開いたときの口に合わせて"(夏水)。
- 上下齿线稿与填色分开,线稿放下面可去除齿间线(ささめた)。
- **提供嘴型指引**:闭口(普通/微笑/へ字)和 あいうえお 的草图,模型师据此变形(ささめた/夏水/双葉うず:あ、い、お、笑顔闭口、普通闭口、むっとした闭口)。
- 【经验值】口内向上下左右各比最大张口多 15–30 px(≈ 10–15%);唇上肤色遮片覆盖口内溢出部分,遮片再比口内大 10–20 px;唇与肤色遮片的接缝要用肤色/线稿吸色画完整。

### 2.4 头发遮挡补全的通用方法

1. 切出最前层的发束,叠回原图——**空洞处**用邻近颜色(吸色/喷枪)补成连续渐变,再补线稿。
2. 补画被前面束压住的"线+色+影",背面转入的部分用影色。【CLIP STUDIO TIPS】
3. 对称或重复的发束:复制镜像后手工修改,避免"看起来是同一束"。
4. 头发与脸/脖/肩的**落影**必须与发束同步拆分。
5. 头发是最大的"发散"型部件:动幅大的束补得最多。

**校准补全量的实操**(推荐):
- 在 Cubism 里先做"极限测试":AngleX/Y/Z 推到 ±30、BodyAngle ±10、EyeBall ±1、MouthOpenY=1~1.5、眼开合 −0.5~1.5,截图查看露底的地方,据此回补——这比预设一个 px 数更可靠。
- "补全量 = 该部件在最大参数下的位移量 + 20–30% 安全边"。【经验值】

- 规则:PSD 越大越好 → 但**图集只放"可见需要的像素量"**,别让所有部件都满分辨率。

## 4. 用 AI 图像工具辅助"补全",而不是"代码硬切"

### 4.1 为什么不是写脚本/规则硬切
- 纯代码/分割(SAM、颜色阈值、轮廓)只能切出**可见**像素,无法产生**被遮挡的内容**:脖子被下巴遮住、头被头发遮住、眼白在虹膜之后、口腔在牙齿后面,都是"画"出来的,不是"切"出来的。所有来源一致强调:拆层 = 切出来 + 补出来。
- 研究佐证(See-through,SIGGRAPH 2026):基线 "SAM+LaMa"(分割+传统修补)在分层重建上 PSNR 14.77 / LPIPS 0.4967,明显低于其"部件一致性扩散+深度排序"方案(PSNR 17.93 / LPIPS 0.3142)——即在该论文的对比中,"分割+通用修补"明显弱于专为动漫分层训练的方案(论文强调发束交错等动漫特有结构);仅为单篇论文的 3 行对比表,不宜过度外推。

### 4.2 现有做法一览

| 做法 | 能做什么 | 适合的拆层环节 | 限制 |
|------|----------|----------------|------|
| **Live2D 官方 Photoshop「素材分割」插件**(裁剪 Crop / 扩展 Expand) | Crop:选一个粗选区,自动识别对象精确形状并切出,可同时生成"填充层"融入周边;Expand:在原图层下方创建像素层,根据原图信息**填充选区内的透明部分**(如帽子内侧、脖子延长);对线稿+填色+阴影+高光多层(含剪贴蒙版)同步处理,会保留原图层结构;可用 GPU。 | 脖子延长、帽内/衣内、小范围背景补全的"第一稿" | 选区外接矩形 ≤ 400 万像素;只是"根据原图信息扩展",不理解结构,线条复杂处要手补。【官方】 |
| **SD/SDXL/Flux 等扩散模型 Inpaint**(A1111/Forge/ComfyUI/Krita-AI) | 对"被遮挡区域"生成补全:如额头发际、被前发遮住的发根、耳廓、眼白被虹膜遮住的部分等 | 脸部与头发补全 | 风格/线条/色彩易漂移,见 4.3 |

### 4.3 常见坑与对策

| 坑 | 表现 | 对策 |
|----|------|------|
| **风格漂移** | 补出来的发丝/皮肤质感与原画不同(过 AI 味、过渲染) | ①使用与原画风格接近的检查点/LoRA(可用原图小样本训练);②**降低去噪强度**(修补 0.25–0.5;替换才用 0.75–1.0)——SD Art:"过高会让结果与图其余部分不一致,过低会模糊,0.5 是好的起点";③用"Only masked"+足够 padding,让模型看到周边上下文;④ControlNet Tile/Lineart 固定内容;⑤只取"轮廓/色块",最终线稿**手描**。 |
| **线条粗细不一致** | 补的线比原线粗/细/断续、抗锯齿不同 | ①固定原图线宽,在大分辨率(≥2×)下补并统一缩放;②用 Lineart ControlNet(动漫线稿预处理器)保线;③对 AI 输出做线稿提取→手工重描(统一笔刷/压感),不要直接用 AI 的像素线;④补线只补"被遮挡的那部分",不改可见线。 |
| **颜色不一致** | 皮肤/发色/阴影色偏,补全区与周边有色块边界 | ①补全层内**吸色**+喷枪过渡;②在 Lab/HSV 下对补全层做颜色匹配(只针对补全区);③用 "Fill/Original masked content" 而非 latent noise(SD Art 指出 latent noise/nothing 常导致灾难);④最后**仅把 AI 输出的遮罩区域**合成回原图。 |
| **补全区域不贴合** | 补画区边缘与原图之间有缝、错位、色带、重复像素 | ①遮罩扩大 4–16 px 并**羽化**;②AI 输出"取遮罩内、边缘留重叠";③合成后在差值模式下检查接缝;④边缘检查 alpha 半透明像素,避免"白边/黑边/光环"(把边缘色向透明区外扩散 1–2 px 再导入)。【经验值】 |
| **结构错误** | 发束数量/方向、耳朵形状、眼白形状不合理 | ①把补全限制为"低风险区"(皮肤底、深色影内、被遮的发根),**高风险区(睫毛/虹膜/牙)手绘**;②先出草图线(Lineart)再填色;③镜像对称区域复制镜像再改。 |
| **分辨率不匹配** | AI 在 1024 左右工作,与 5000 px 画布不匹配,细节软、纹理断层 | ①局部裁切 + Only masked(把局部放到 1024–1536 工作尺寸);②放大后用动漫超分(Real-ESRGAN anime 等)统一;③网点/笔触纹理手动补;④输出再与原图叠放检查。 |
| **Alpha 与透明** | 部分模型输出"棋盘"/半透明边缘、不能直接带 alpha | ①用 Latent-Transparency 类方法/RGBA 模型(See-through、Qwen-Image-Layered 提供 RGBA),或在纯白/纯黑背景各出一次再抠;②补全层只在需要处保留 alpha。 |
| **图层顺序/混合模式失真** | 阴影用乘算后叠加变深 | 分割阶段阴影色用"正常",最后只输出 正常/正片叠底/添加三种。 |
| **合规/客户政策** | 部分接单/发布平台或客户限制 AI 生成内容 | 交付前和客户/平台确认 AI 使用规则并留存工作文件(本调研未查具体平台条款,不做断言)。 |

### 4.4 推荐的"AI 辅助拆层"流程(保证重新拼合后仍符合审美)

1. **准备**:原图 5000+ px,先在原图上建参考组。若原画是单层,先用 SAM/手动选区 + 官方插件 Crop 切出每个部件,保留"素材分割用 PSD"。
2. **逐部件补全**(按 2.0 的"从前到后"顺序):
   1. 把该部件周边**被遮挡区域**的遮罩画出来(范围参考 §2.1 的补全范围;可设成最大形变位移 + 20–30%)。
   2. 先用"吸色 + 喷枪"手工铺**底色/阴影色块**(AI 只管细节,颜色基准人工定)。
   3. 对遮罩区域做 Inpaint(Only masked、padding 32–128 px;去噪 0.3–0.6;ControlNet:Lineart + Tile 或 Inpaint-only;固定同一检查点/LoRA/种子策略),**每次出 4–8 张,挑最贴合的**。
   4. 把 AI 输出放在**新图层**(原部件之下),用图层蒙版只露出遮罩区域;**不覆盖原图可见像素**。
   5. 线稿:对补全区做线稿提取,用与原线同色/同宽的画笔**手工重描一遍**统一风格;高风险区(睫毛、虹膜、牙齿、嘴唇轮廓)人工重画。
3. **叠回原图检查**(CLIP STUDIO TIPS 强调的步骤):把所有部件按顺序叠放,设"差值(Difference)"在原图上方 → 可见区应接近纯黑;不一致的地方就是拆分/补全错位。再看**颜色/线宽/阴影一致性**。
4. **形变检查**:在 Cubism 中提前做极限测试(见 §2.4),把仍露底的地方补回素材分割 PSD(而非只改导入 PSD)。
5. **统一**:全模型做一次"风格一致检查":线宽、描边色(线稿颜色是否同系)、阴影色阶(层数)、高光形状、网点/纹理密度;对不一致层做统一(重描线、色阶匹配)。
6. **合并输出**:每部件合并为单层 → `xxx_import.psd`;保留 `xxx_素材分割.psd`。检查同名图层、隐藏层、杂点、蒙版(应用图层蒙版)、路径信息。

## 5. 导入 PSD 前的检查清单(官方+多源)
