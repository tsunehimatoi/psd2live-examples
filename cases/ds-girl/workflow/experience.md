# ds-girl 制作过程体验


# TL;DR
鲸鱼女孩形象是一个受人工介入较高，需要多次进行返工的工程项目，但受人工监督后总体 Live2D 形象表现可用。
受人工监督成本大约需要开发者与 Agent 协作，完成总时长大约 30 小时。

> 备注：已准备好拆分好的 PSD 图片，不使用 PSD2live 的拆分物件功能（比方说上下嘴图层拆分）



## 成果与制作步骤

#### 成果物
- 角色：鲸鱼女孩
- 图层：共 40 层（37 层在 PSD 组装好 + 3 层在 PSD2Live 后加入 层）
- 编辑历史：按所有保留分支中实际改变工程 revision 的历史提交统计，共 **1,273 次**，其中用户 **757 次**、Agent **516 次**。



#### 用户与 Agent 编辑内容归纳

| 参与者 | 主要编辑内容（仅根据历史节点名称归纳） |
| --- | --- |
| 用户（757 次） | 具名操作以画布几何变形（158 次）和通用编辑器修改（83 次）为主；另有物理组（29 次）、画布权重（16 次）、绘制顺序、源图绘画，以及少量骨架、动作、参数和模拟调整。 |
| Agent（516 次） | 动作编辑（143 次）数量最多；还进行了眼睫与眼睛、鼻子、脸颊、尾巴和服装等部件精修，以及摆动、物理、模拟、图层导入与分类、网格和工程设置，并通过 bisect/probe 类节点进行试验排查。 |



#### 制作步骤

1. 原始立绘插画理解 PSD2Live 项目部件的[命名规范](https://github.com/tsunehimatoi/psd2live/blob/master/docs/zh/spec/PSD_LAYER_SPEC.md)，明确需要拆分的部件，拆分图（如闭眼、张嘴）额外生图生成。
2. **不采用 See-Through 模型拆分**，使用其它生图模型对已声明的部件进行拆分，并由 Agent 进行组装 PSD 图层。
3. 源码编译启动 PSD2Live ，导入 PSD 文件，并开启 MCP 服务给 Agent 链接。
4. 基础建模：九轴、人物上可进行物理模拟的物件、尾巴动效。
5. 优化建模：五官、身体细节。

#### 环境与工具

- PSD2Live 版本：3.4.3
- 平台：MacOS 源码编译打开，MacBook Pro M3
- AI 客户端与模型：Kimi Code，Kimi K3



## 任务反馈
**Live2D 建模任务与主观效果反馈**：

| 建模任务 | 效果反馈 | 主观评价 |
| --- | --- | --- |
| 九轴转头 | 约 45 度 | **较优** |
| 尾巴摇摆 | 除常见左右摇摆外，可物理模拟出远近的 Z 轴效果 | **较优** |
| 眨眼差分与原始眼睛 | 使用拆分图层编辑闭眼；若未特殊说明拆分图层与原本眼睛的关系，Agent 编辑时会忘记隐藏原本眼睛。 | **较差** |
| 小部件的物理摇摆 | 领带、裙摆这类名称含有明确语义的可形变的部件，Agent 可较容易理解并很清晰的加入物理模拟，并准确刷出物理权重和需要形变的顶点 | **优** |
| 耳朵的刚度 | Agent 对于耳朵柔软程度理解清晰，准确判断出耳朵摇晃需要的动作强度 | **优** |
| 眼睛复杂度 | 高光、果冻眼还需要返工描述形变强度、图层关系 | **较差** |



**PSD2Live 体验薄弱的地方**：

- **人类和 Agent 共同编辑时，人类需要暂停操作**。Live2D 建模过程中，由于角色形象仍需依赖人类审美判断，与 Agent 共同编辑过程中会因为人类操作（比方说顶点编辑、刷物理权重时等需要烘焙的操作）而修改失败，在 Agent 编辑时需要人类停止操作，效率受影响。
- **跨版本工程文件的稳定性**。本人物模型在v3.0.1版本编辑，在v3.4.3版本更新，导出 Live2D `cmo3` 文件（Cubism 5.3）后，`cmo3`文件出现头发丢失，同理新版本工程文件无法在 Vtube Studio 打开 `moc3` 模型。可能是旧版本 v3.0.1 的 BUG，初步判断该问题属于老版本问题，再修复老版本 BUG 价值较低。可在新版本迭代开发时增加测试判断多版本工程文件的兼容。
- **工程文件体积在 Agent 多次验证图片后会异常增大**。每次 MCP 连接 Agent 都会请求画布视图（类似于 Agent 想看一遍）导致每一次连接都会产生一张快照存放在 `psd2live` 工程文件中，在 Agent 编辑动画效果时会异常增多，导致 `psd2live` 工程烘焙、加载新文件操作变得非常缓慢。
- **新打开 PSD2Live 工程文件时需要加载较久时间**。





## 可参考的Agent编辑记录

- 物件刚度、权重：当编辑细节部件时，可以先描述该部件属于什么物体，在附着物体上是什么关系，无需再进行详细的编辑方法即可让 Agent 准确编辑，相关文档（例如[摇摆生成](https://github.com/tsunehimatoi/psd2live/blob/master/docs/zh/guide/SWING.md)）已对部件描述清楚使用方式。同理其他网格、参数、骨骼都已有成熟的经验文档进行描述，在物件的初次编辑时有较好的效果。
- 增加动效、或例如眨眼张嘴动画时，可描述 Agent 通过 `XX` 时间频率截图，让 Agent 通过多次截图了解修改结果，让动画形变的编辑更准确。
- 对于形变后的验收方式仍需人工评价。Agent 编辑后的成果依赖于模型的审美、生成倾向，只对数值型成果验证有效。因此对于审美上的验证，推荐以经验或参考图方式留存形变后的精准位置，以便于人物形象稳定。
- PSD2Live的优秀历史提交的设计，支持 Agent 遴选跳转其他分支去对错误编辑、崩溃版本进行编辑版本回退，有便于错误排查和问题分析，推荐建模出现问题时可多利用此设计。
