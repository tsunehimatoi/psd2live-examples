本案例的素材、工程及展示输出按 **CC0 1.0 Universal** 发布。作者与来源信息作为资料保留。

## 使用步骤

1. 在示例仓库运行 `python scripts/fetch.py --case ds`，或在主仓库运行 `python tools/examples/fetch.py --case ds`。
2. 在 PSD2Live 中打开 `examples/ds/psd-input/ds.psd`。导入 PSD 后生成模型，预览动作和物理，检查导出文件。
3. 从 `.model3.json` 加载已有运行时输出，并保留其引用的纹理、动作和物理文件。CMO3 用于编辑器检查，诊断 JSON 用于分析。
